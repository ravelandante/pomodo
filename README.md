# Pomodo

A simple Pomodoro timer for Raycast.

## Features

- Menu bar actions for starting a focus, break, or long break session
- Menu bar timer for current session
- Recording, storing, and viewing of accomplishments and learnings for each focus session
- Separate Raycast main window command for controlling sessions

Requires the [Do Not Disturb](https://www.raycast.com/yakitrak/do-not-disturb) extension to toggle do not disturb when in a focus session.
